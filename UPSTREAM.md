# Foundation and provenance

Paperwork is an original behavioural implementation, not a fork or vendor source release. Its current baseline and Pip configurations share `PaperworkCore`; baseline preserves plain AppKit controls and Pip adds original styling. The planned release split places a separately verified reference recreation in its own repository and the custom Pip/Plus configurations here. Neutral Plus/Pip Plus source now builds locally with matched OCR-language and inspector controls, but native qualification and releases remain pending. Current neutral workflow tests do not establish PDF Expert layout parity. Original app/helper source is MIT, copyright 2026 Ghostzy0, except separately identified test-tool dependencies used only to regenerate synthetic fixtures.

Runtime dependencies are macOS system AppKit, PDFKit, Vision, CoreGraphics, CoreText and CryptoKit. No Apple framework binaries are bundled or relicensed. Swift Package has no external Swift packages. The bundled canonical writer pins Apache-2.0 pdfcpu v0.16.1 with exact Go 1.26.0 and locked transitive modules. See Engine/Notices for their licences, embedded Roboto/Adobe metrics notices and build-time Go licence. Build uses the installed Apple SDK and command-line tools under their existing terms. No model weights, language packs, remote fonts, telemetry, provider credentials or cloud inference are shipped. English on-device Vision OCR uses system resources; hardware/OS can affect recognition.

Workflow references: [PDF Expert](https://pdfexpert.com/) and [Adobe Acrobat](https://www.adobe.com/acrobat.html), unaffiliated proprietary products. No reference source, branding, exact visual expression or media is redistributed. PDFKit remains the native viewer. Native saved-output tests exposed canonical button and font-stream defects; pinned pdfcpu now parses, validates and normalises output. PDF.js and Tesseract are not included.

The Pip character and motion here are newly authored AppKit drawing/behaviour. The private reserved Pip motion engine is not a dependency. System font and SF Symbols are rendered by macOS, not bundled assets. Screenshots contain only original synthetic documents. Fixture generation tools (reportlab/pypdf/Pillow) are development-only and their own licences apply; checked-in fixture PDFs contain authored test content rather than copied documents.

The neutral document and Pip pebble app icons are original MIT artwork generated by `assets/generate_icons.py`. Their checked-in ICNS files are copied directly by the normal build; regeneration optionally uses Pillow and macOS `iconutil`, with no downloaded artwork or fonts. The small PNG previews are development review images. Regeneration is not needed to build or run the app.

Build toolchain used during development: Apple Swift 6.4, SDK macOS 27.0, Apple arm64; minimum requested deployment target 14.0. Cross-version compatibility needs runtime evidence on those older releases.
