# Security

Experimental PDF tooling handles complex untrusted files. Keep macOS patched, preserve originals and verify important outputs independently. This app does not implement secure redaction, certificate signing or signature validation. Its conservative read-only policy for encrypted/restricted/signed input is a safety boundary, not a cryptographic guarantee.

Report ordinary reproducible defects through repository issues using synthetic files. For suspected vulnerabilities, avoid publishing sensitive inputs or exploit-bearing personal documents; use GitHub's private vulnerability reporting if enabled, or request a private reporting route from the maintainer. No response-time guarantee is made. Never include credentials, identifying document content or system logs with secrets.
